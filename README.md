# Тупка — онлайн карточная игра (2–6 игроков)

Полноценный проект: Node.js + Express + Socket.io на сервере, чистый HTML/CSS/JS на клиенте.
Игроки заходят с разных устройств через интернет по 4-значному коду комнаты.

## Реализованные правила

- 36 карт, козырь **всегда черви**.
- Старшинство как в дураке: 6 7 8 9 10 В Д К Т.
- **Пики** — отбить пику может только более старшая пика. Козырем пику бить нельзя.
- **Перевод карты**: пока защитник ещё не отбил ни одной карты в раунде, он может перевести
  атаку следующему игроку картой того же достоинства. При игре **вдвоём** перевод тоже
  разрешён — карта возвращается первому атакующему, и он становится защитником.
- **Дама останавливает подкидывание**: если отбились дамой — остальные игроки больше не могут
  подкидывать в этом раунде.
- **Шестёрки** может подкинуть любой игрок атакующей стороны в любой момент, даже если
  подкидывание уже запрещено дамой, и даже если на столе ещё нет шестёрки.
- **Нарушения правил** (бить пику козырём, подкидывать не в масть/не в ранг, подкидывать
  после дамы, переводить не той картой) сервер отклоняет автоматически и **штрафует**:
  игра приостанавливается, и каждый живой игрок (кроме нарушителя) сам выбирает в интерфейсе,
  какую карту из своей руки отдать нарушителю. Игра продолжается, когда все должники расплатились.
- Побеждают все, кто избавился от карт при пустой колоде; последний игрок с картами на
  руках — «тупка» (проигравший).

## Запуск локально

```bash
npm install
npm start
```

Откройте `http://localhost:3000` в браузере. Для игры с друзьями по сети — откройте порт 3000
наружу (например, через ngrok: `ngrok http 3000`) и поделитесь ссылкой + кодом комнаты.

## Проверка игровой логики

```bash
node test.js
```

## Деплой на Render (бесплатный вариант)

1. Залейте эту папку в GitHub-репозиторий.
2. На [render.com](https://render.com) создайте **Web Service**, подключите репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. После деплоя откройте выданный Render URL — это и есть адрес игры, им можно делиться.

## Структура проекта

```
server.js       — Express + Socket.io, комнаты, рассылка состояния
game.js         — вся игровая логика и правила «Тупки»
test.js         — быстрые проверки ключевых правил
public/
  index.html    — разметка экранов (главная / лобби / игра)
  style.css     — оформление карточного стола
  client.js     — рендер состояния и обработка действий игрока
```

## Возможные доработки

- Голосовой/текстовый чат в комнате.
- Переподключение по имени, если игрок случайно закрыл вкладку (сейчас место сохраняется,
  но нужно зайти с тем же сокетом до перезагрузки).
- Звуковые эффекты и анимация раздачи карт.
- Настраиваемое количество карт в раздаче или колода на 52 карты.
